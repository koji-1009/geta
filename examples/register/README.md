# register

A register of users and teams. It is the canonical shape of a geta application. It serves from memory; [`../register-sql`](../register-sql) serves the same routes from SQLite or PostgreSQL.

| Pattern | Where |
| --- | --- |
| A route per directory, `geta sync`, `options.go`, `env_test.go` | `routes/`, `routes/zz_routes.go`, `routes/options.go`, `routes/env_test.go` |
| Secure by default (a bearer token everywhere), admin-only writes in `Doc.Scope` | `routes/scope.go`, `auth/auth.go`, `routes/users/route.go` |
| Failure tables shared through `slices.Concat`, problem types telling two 409s apart | `failures/failures.go`, `routes/users/import/route.go` |
| `ETag` and `If-Match` against lost updates, checked inside the store's write | `routes/users/id_/route.go` |
| PUT that creates (`If-None-Match: *`, `CheckAbsent`) or replaces (`If-Match`, `Check`) | `routes/teams/team_/route.go` (`Put`) |
| PATCH as a JSON Merge Patch: `geta.Nullable` + `omitzero` (absent keeps, null clears, a value sets), with `If-Match` | `routes/teams/team_/route.go` (`Patch`, `TeamPatch`) |
| Multipart upload of one file, and of several (`[]geta.File`) | `routes/users/id_/avatar/route.go`, `routes/users/id_/attachments/route.go` |
| An event stream | `routes/users/events/route.go` |
| Credential-free CORS (`*`) with conditional writes from a page | `routes/scope.go`, `cors_test.go` |
| The typed Go client (`getaclient`) with the handlers' own types | `client_test.go`, `attachments_test.go` |

## Run

```
go run ./examples/register -addr 127.0.0.1:8080
```

Demo bearer tokens: `t-admin` (an administrator; can write) and `t-user` (can read).

```
curl -s -H 'Authorization: Bearer t-admin' -H 'Content-Type: application/json' \
  -d '{"id":"ada","name":"Ada","role":"member","tags":[]}' http://127.0.0.1:8080/users
curl -si -H 'Authorization: Bearer t-admin' -H 'If-None-Match: *' -H 'Content-Type: application/json' \
  -X PUT -d '{"name":"Core","description":"the platform"}' http://127.0.0.1:8080/teams/core
curl -si -H 'Authorization: Bearer t-admin' -H 'Content-Type: application/merge-patch+json' \
  -X PATCH -d '{"description":null}' http://127.0.0.1:8080/teams/core
curl -s -H 'Authorization: Bearer t-admin' -F file=@go.mod -F file=@README.md -F note=two \
  http://127.0.0.1:8080/users/ada/attachments
```

## Test

```
go test ./examples/register/...                                  # from the repository root
go test ./examples/register -run TestOpenAPIGolden -update        # rewrite openapi.json after a reviewed change
go run github.com/koji-1009/geta/cmd/geta sync -check examples/register/routes
```

## Client check

A client generated by `openapi-python-client` from `openapi.json` calls the running server. The script checks every status it meets against the document. Its docstring has the commands:

```
uvx openapi-python-client generate --path openapi.json --output-path $OUT --overwrite
go run . -addr 127.0.0.1:18080 &
uv run --with $OUT --with httpx python clientcheck/roundtrip.py http://127.0.0.1:18080 t-admin
```
